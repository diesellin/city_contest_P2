# 最短路與標記收集

給定一張包含 $N$ 個點、$M$ 條邊的有向帶權圖。節點編號由 $1$ 到 $N$，以節點 $1$ 為起點、節點 $N$ 為終點。

圖上會進行 $Q$ 次標記操作，每次操作給定三個數值 $(x, d, c)$：
* **標記規則**：檢查從節點 $x$ 出發的所有直接出邊。若該出邊的權重 $w$ 滿足 $d < w$（即距離 $d$ 落在該邊內部，未到達下一個節點），則將這條出邊畫上標記（顏色）$c$。一條邊可以同時疊加多個標記。

### 求解目標
請在所有從節點 $1$ 走到節點 $N$ 的**最短路徑**中，找出那一條能夠收集到**最多不同種類標記**的路徑，並輸出該路徑的總長度與所收集到的標記種類數量。

若從節點 $1$ 無法到達節點 $N$，請輸出 `-1 -1`。

## 輸入格式 (Input Format)

* 第 $1$ 行包含三個整數 $N, M, Q$，分別代表節點數、邊數以及標記操作數。
* 接下來 $M$ 行，每行包含三個整數 $u, v, w$，代表一條從節點 $u$ 連向節點 $v$、權重為 $w$ 的有向邊。
* 接下來 $Q$ 行，每行包含三個整數 $x, d, c$，代表一次標記操作。

## 輸出格式 (Output Format)

* 請輸出單行兩個由空白隔開的整數：
  * 第一個整數為從節點 $1$ 到節點 $N$ 的最短路徑長度。
  * 第二個整數為在所有最短路徑中，能收集到最多不同種類標記的數量。
* 若起點無法連通至終點，請輸出 `-1 -1`。

## 資料範圍與限制 (Constraints)

* $1 \le N \le 10^3$
* $1 \le M \le 10^5$
* $0 \le Q \le 10^5$
* $1 \le u, v \le N$
* $1 \le w \le 100$
* $1 \le x \le N$
* $0 \le d < 100$
* 標記顏色種類 $0 \le c \le 6$（最多 $7$ 種標記）

## 子任務 (Subtasks)

1. (5 points) $W \le 1$ 且 $Q = 0$
2. (10 points) $Q = 0$
3. (35 points) $M \times Q \le 10^7$
4. (50 points) 無額外限制

## 範例測資 (Examples)

### 範例 1

#### 輸入
```
4 4 2
1 2 2
2 4 1
1 3 1
3 4 2
1 0 0
2 0 1
```

#### 輸出
```
3 2
```

#### 範例說明 1
* 共有兩條從 $1$ 到 $4$ 的最短路徑，路徑長度皆為 $3$：
  * 路徑一：$1 \to 2 \to 4$（長度 $2 + 1 = 3$）
  * 路徑二：$1 \to 3 \to 4$（長度 $1 + 2 = 3$）
* 操作 `1 0 0` 將邊 $1 \to 2$ 與 $1 \to 3$ 標記上顏色 $0$。
* 操作 `2 0 1` 將邊 $2 \to 4$ 標記上顏色 $1$。
* 路徑一收集到標記 $\{0, 1\}$，共 $2$ 種。
* 路徑二收集到標記 $\{0\}$，共 $1$ 種。
* 最佳選擇為路徑一，輸出路徑長 $3$ 與最多標記種類數 $2$。

#### 輸入
```
3 1 0
1 2 5
```

#### 輸出
```
-1 -1
```

#### 範例說明 2
無法從起點 $1$ 走到終點 $3$，因此輸出 `-1 -1`。
