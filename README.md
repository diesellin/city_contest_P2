# 最短路與標記收集 (`marathon`)

城市賽題目 P1，使用 [TPS](https://github.com/ioi-2017/tps) 格式的出題包。

## 題目概述

給定 $N$ 個點、$M$ 條邊的有向帶權圖，起點為 $1$，終點為 $N$，邊權 $1 \le w \le 100$。
另有 $Q$ 次標記操作 $(x, d, c)$：對從節點 $x$ 出發、且權重 $w > d$ 的每條出邊，標上顏色 $c$（$0 \le c \le 6$，共 $7$ 種，一條邊可疊加多個標記）。

在所有從 $1$ 到 $N$ 的**最短路徑**中，找出收集到**最多不同種類標記**的路徑，輸出最短路長度與最大標記種類數；若不可達，輸出 `-1 -1`。

完整題面見 [`statement/index.md`](statement/index.md)。

> [!NOTE]
> **關於終點的標記**：路徑抵達終點 $N$ 時，位置 $(N, 0)$ 上的標記也算收集到，即所有 $x = N$ 且 $d = 0$ 的操作所標的顏色都要計入答案（$N = 1$ 時起點即終點，同樣適用）。題面已明確寫出這條規則。

## 範圍與限制

| 項目 | 限制 |
|---|---|
| $N$ | $\le 10^3$ |
| $M$、$Q$ | $\le 10^5$ |
| 邊權 $w$ | $1 \le w \le 100$ |
| 時間限制 | 1 秒 |
| 記憶體限制 | 512 MB |

| 子任務 | 分數 | 限制 |
|---|---|---|
| 1 | 5 | 所有邊權 $w = 1$ 且 $Q = 0$ |
| 2 | 10 | $Q = 0$ |
| 3 | 35 | $M \times Q \le 10^7$ |
| 4 | 50 | 無額外限制 |

## 標準解法（`solution/correct.cpp`）

利用邊權很小（$\le 100$）把圖展開：

1. 把每個點 $a$ 展開成一條長 $102$ 的鏈 `id[a][0..101]`，相鄰兩點長度為 $1$。
2. 邊 $(a \to b, w)$ 改成從 `id[a][w-1]` 連到 $b$，走完這條邊恰好經過 `id[a][0..w-1]`，長度為 $w$。
3. 操作 $(x, d, c)$ 變成「在節點 `id[x][d]` 上放顏色 $c$」，剛好對應「$d < w$ 的出邊」才會經過它。
4. 展開後所有邊長為 $1$，對狀態 `(節點, 顏色集合 mask)`（$2^7 = 128$ 種）做 BFS，用 `hg[mask][節點]` 去重。BFS 第一次到達終點的層數就是最短路長度，在該層的所有 mask 中取最大的 popcount。

複雜度約為 $O\big(2^7 \cdot (102 N + M)\big)$，最多約 $2.6 \times 10^7$ 次轉移。實測最慢的測試約 0.3 秒，記憶體約 24 MB。

## 測資

`tests/` 由 `gen/data` 產生，共 58 個測試：

| 子任務 | 內容 |
|---|---|
| 樣例 | 2 個公開範例 |
| 1 | $N = 1$、自環與重邊、反向邊不可達，以及隨機 / DAG / 鏈 / 不可達圖 |
| 2 | 最大邊權、平行邊取最短、$N = 1000$ 全 $w = 100$ 長鏈（答案 $99900$） |
| 3 | 手工邊界用例、分層圖，以及 $M \times Q$ 剛好在 $10^7$ 的測試 |
| 4 | 分層圖（最短路約 $10^{10}$ 條）、鑽石鏈（約 $10^{150}$ 條）、終點不可達的最壞狀態數用例、$M = Q = 10^5$ 的滿規模測試 |

手工用例涵蓋的邊界：

- $N = 1$（起點即終點）。
- $(N, 0, c)$ 計入、$(N, d>0, c)$ 不計入。
- $d = w - 1$ 計入、$d = w$ 不計入。
- $w = 100,\ d = 99$。
- 平行邊、環、自環、重複操作。
- 終點不可達但終點上有標記。
- 較長路徑標記更多也不能選。
- 7 種顏色拉滿、7 級鑽石鏈。
- 兩個「貪心殺手」用例：每個點只保留當前最優集合的做法會錯。

## 使用方式

需要先安裝 [TPS](https://github.com/ioi-2017/tps) 與 `g++`。

```bash
tps gen      # 重新產生 tests/（會先清空 tests/，並用 correct.cpp 產生輸出）
tps verify   # 檢查設定檔格式
tps --help   # 其他指令
```

> [!TIP]
> `tests/`、`logs/`、`sandbox/` 不會被提交到 git，克隆本倉庫後執行 `tps gen` 即可重新產生全部測資。

新增測資時，在 `gen/data` 對應子任務的末尾加一行，例如：

```
gen2 layered 31 32 2 30 s4_5      # 分層圖：L=31, W=32, K=2, Qm=30
manual m_end_mark.in              # gen/manual/ 下的手工測資
```

`gen2` 的用法見 [`gen/gen2.cpp`](gen/gen2.cpp) 開頭的註解。
